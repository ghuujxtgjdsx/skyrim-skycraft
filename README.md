## Overview

SkyCraft overhauls Skyrim's smithing system with material-progression crafting recipes that logically require component items, new weapon and armor tiers between vanilla materials, a complete cooking and alchemy supply crafting branch, and a dynamic recipe discovery system where players must find crafting manuals or experiment to unlock advanced recipes.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Skyrim SkyCraft** delivers the features you need in a clean, intuitive package.
